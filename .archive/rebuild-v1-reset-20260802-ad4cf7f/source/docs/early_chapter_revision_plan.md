# 早期三章返修计划

## 触发原因

作者确认第1、2、3章都需要返修，否则早期规格不一致的问题仍然存在。

## 硬性约束

- 第1章第1-40节已经发布，正文内容冻结，不做改写。
- 第1章只能从第41节开始返修、扩写与续接。
- 第1章不强制扩到120节，以第41节后读感满意、每节约2000字为准。
- 第2章整章返修扩写，从第2章开始执行不少于120节、每节约2000字。
- 第3章已有150节，节数达标，但需要复核每节密度、标题格式和残留旧表达。
- 长章底线从第2章开始执行：每章不少于120节，每节约2000字；超过120节可以，不能为了卡目标压缩有效场景。
- 正文分节标题采用纯文本 `001｜节名`，不使用 Markdown 标题。
- 叙事视角保持第三人称限知，紧贴林时；对话、备忘录、通信内容可出现第一人称。

## 分批顺序

1. 修第1章41节后：先保证每节密度、衔接和第2章入口，不强制120节。
2. 第1章读感满意后做 reader review。
3. 第2章整章扩写到120+节，并同步更新章纲/索引；当前优先执行。
4. 第3章按150节逐批补短节、改标题格式，复查AI味与视角。
5. 统一运行结构检查，更新 `story.md`、记忆与提交。
