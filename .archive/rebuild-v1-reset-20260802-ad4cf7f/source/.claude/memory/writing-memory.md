### 9. 规则：高频主题词要用动作和物件降噪

- **阶段:** 正文
- **类型:** 规则
- **领域:** 读者体验 / 反AI / 高压对话
- **原文:** 第三章二次 reader/review 后，保留“答案/能说/纸本/酸奶”等主题锚点，但削减顾铮夜谈中过密的“答案/规则”判断句，把部分解释改成指节敲桌、杯子、烟灰缸、鸡蛋饼油纸等动作和物件。
