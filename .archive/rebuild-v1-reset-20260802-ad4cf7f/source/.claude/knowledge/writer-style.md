## 已有作者偏好（来源可追溯）

- [writer-preference] 使用第三人称限知，紧贴林时的观察、迟疑与自嘲；不把第三人称机械替换成远距离旁观。来源：`settings/writing-style.md` §§role、possible_mistakes；`.claude/memory/writing-memory.md` 条目 1。
- [writer-preference] 情绪主要通过动作、细节、物件和留白传递，不直接抒情或替角色贴标签。来源：`settings/writing-style.md` §§core_principles、depiction_techniques。
- [writer-preference] 高压流程／证据段要以食物、台阶、酸奶、伤口、手边物件或身体代价降噪，避免抽象流程词连续堆叠。来源：`.claude/memory/writing-memory.md` 条目 3、9、10；`.claude/memory/chapter-memory.md` 条目 1。
- [writer-preference] 青春群像日常必须与主线证据互相咬合；轻松类比优先交给贺鸣等外放角色，林时旁白保留少量锋利自嘲。来源：`.claude/memory/chapter-memory.md` 条目 2；`.claude/memory/writing-memory.md` 条目 11。
- [writer-preference] 系统灰字、关键词定名与终局提示应分阶段释放；完整灰字通常落在真正章末，前后不追加情绪总结。来源：`.claude/memory/writing-memory.md` 条目 4、12。
- [writer-preference] 正文分节采用纯文本 `001｜节名`；节名短、冷、有信息量，不使用 Markdown 标题，也不剧透未揭底牌。来源：`.claude/memory/writing-memory.md` 条目 5；`.claude/memory/chapter-memory.md` 条目 5。
- [writer-preference] 长章目标以叙事完整度优先；第一章不为凑节数硬扩，第二章及后续的节数／字数规格须在 rebuild-v1 按章复核。来源：`.claude/memory/writing-memory.md` 条目 4、6、7。
- [writer-preference] 灰色人物须呈现可理解但不替其洗白的逻辑；关键解释分阶段放出，避免长篇独白。来源：`.claude/memory/writing-memory.md` 条目 1；`settings/writing-style.md`。
