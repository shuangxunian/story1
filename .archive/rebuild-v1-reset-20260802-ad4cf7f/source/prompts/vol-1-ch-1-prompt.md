## 角色

你是一个都市异能方向的玄幻小说作家。

## 任务指示

创作第一卷第一章《静》，全卷作用是“陌生与微暖”的入口：让林时从普通运维实习生被迫进入学院与 A-2，确认“静”是有代价的自保与互助能力，并把西南异常复核留为下一章的可执行任务。按写作风格规定的单节篇幅完成约 70 节，正文分节固定使用纯文本 `001｜节名`，节名短、冷、有信息量，不使用 Markdown 标题。

本章驱动力：悬疑与威胁并行。林时想回到普通生活，夜巷、灰纹和学院的有限选择持续证明他回不去；他每多得到一条可验证的事实，新的解释缺口就出现。

信息释放节奏：前段只给失声、冷、封锁和被带走的现象；中段给“静”能短暂压住异常、学院能提供有限保护这两条事实；后段用陆沉的短暂安稳与西南碎词交付关系回报和行动入口。设定、机制与学院立场必须拆进训练、登记、站位和对话，不作集中讲解。

### 叙事目标

1. 核心悬念：夜巷为何失声，林时身上的“静”究竟把他带进了什么处境？本章结束时加深并转移为“西南的信号是什么，A-2 会在那里碰到什么”。
2. 读者离场感受：台阶上的短暂安稳刚落下，远处低频又碰到灰纹，手里多了一张必须出发的任务单。
3. 爽点设计：成长型、关系型微兑现。铺垫于场景 033—045 的失控训练与陆沉边缘化，释放于 043—045：林时让陆沉获得两秒安静，但立刻因低温、耳鸣和视野发白被迫撤开；不写碾压或胜利宣言。

### 写作方法论

动笔前按以下顺序执行：

1. 焦点锁定：每个场景只抓一个核心冲突、一个人物情绪出口或一组信息差。高权重段的笔墨集中在林时的动作、感官和代价，背景人物与环境只留能推动当前镜头的部分。
2. 感官分层取舍：每个场景只细化两种感官。夜巷以听觉和触觉为主；学院日常以物件触感和人声为主；陆沉失控以低频、潮湿声与灰纹低温为主。禁止五感齐铺。
3. 叙事节奏交替：密集动作或短对话后，留一小段身体反应或生活物件，再用一句轻环境过渡。高压处短句、断段；日常处允许松散句和不完全对话。避免连续长描写、连续纯台词和通篇等长段落。
4. 信息释放控制：只写林时当场看到、听到、触到与能据此判断的部分。所有谜底只给碎片现象和当下后果，不补全因果。

## 背景信息

### 前情上下文

无前置章节，开篇直接切入林时当下行动。不要用世界起源、学院历史或设定总览开场。

### 角色初始状态

**林时：**
- 起点：城南小公司角落工位的运维实习生，护着电脑包、盯告警和拒信，把存在感低当作省事；晚间会把想说的话删成一句“吃了”。
- 经历：夜巷被迫压住异常外放；在据点、出租屋、总部和训练场反复试探自己能否回去；在陆沉失控时短开“静”。
- 终点：签入 A-2 的入编观察，手背灰纹仍冷，知道能力能帮人也会伤身；将“西南、信号、别开太久”记进备忘录，准备跟队复核。
- 微习惯：手机备忘录只写确认过的时间和身体反应；紧张时把手背往袖口里藏；自嘲锋利但不把自己说成英雄。

**许岚：**
- 起点：夜巷现场的处置队长，以站位、撤离线和短命令控制局面。
- 经历：将林时置于监护、训练和报告边界内；在陆沉事件中命令林时撤开。
- 终点：确认林时进入 A-2，但只承诺明确边界，不承诺全部真相。
- 微习惯：先看人站的位置，再下命令；帮助人时说得像流程通知。

**顾铮：**
- 起点：在临时据点带水和观察表出现，黑眼圈、搪瓷杯、说话慢。
- 经历：给林时可验证的有限解释，拒绝把未经确认的部分说成答案；提醒陆沉的事不能由林时独自承担。
- 终点：仍保留解释优势，只把“先过今晚”“先学会边界”留给林时。
- 微习惯：杯沿、停顿、短句；不以长篇导师独白安抚人。

**贺鸣：**
- 起点：A-2 里的同期新人，先拿食物和过量自我介绍接近林时。
- 经历：带林时认识食堂和台阶，在训练后塞半个馒头，在观察室外放原味酸奶。
- 终点：与林时、陆沉形成“先把人留在身边”的台阶互助。
- 微习惯：话多松散，压力越大越会拿报销、外卖、食物打岔；食物不是装饰，而是他确认人还在的方式。

**陆沉：**
- 起点：训练场边独处，周围留出空圈，压着耳侧听别人听不见的声音。
- 经历：被“静”短暂压住潮湿低频，能抬头、呼吸、坐到台阶上。
- 终点：只留下“西南”“下面”“别开太久”等碎词，不能给出解释或完整情报。
- 微习惯：极短句、沉默、把手从耳侧放下或盯住远处；原味酸奶和台阶空位是他的日常锚点。

## 案例

**夜巷有限解释的写法参考：**

林时靠墙停住，鞋底在积水里蹭出一点响。许岚没回头，只抬手把他按在封锁线外。

“别动。”

林时把发凉的手背塞进袖口。“我本来也没想报名夜游项目。”

许岚看了一眼他没藏住的灰纹，递来一瓶没拧开的水。“看见什么，写什么。别给它起名字。”

这里的写法必须服务于具体信息差：许岚知道林时已卷入异常，林时只知道自己刚压住过什么。许岚用站位、递水和短命令回避全貌；林时用一句自嘲遮住发抖。紧张段只留短句、脚步、水声和手背低温，不接解释世界观。

**台阶微暖的写法参考：**

贺鸣把酸奶放在台阶中间，瓶盖拧得歪七扭八。“原味，别嫌。这里能买到的正常东西不多。”

陆沉坐在最远那一级，没有接话。林时没开“静”，耳边的低频仍隔着墙蹭过来。他把手压在膝盖上，没碰那瓶酸奶。

过了片刻，陆沉把瓶子拿走，只说：“别久。”

这段的焦点是三人刚建立的互保，不是解释陆沉。贺鸣用食物和废话递出善意，陆沉用短词划边界，林时以克制回应；舒缓段允许停顿和无效话，但低频、未开的能力和灰纹把危险留在画面里。

## 输出

### 写作规范

**视角策略：** 全章第三人称贴身限知，镜头只跟林时。只写他看见、听见、触到、闻到，以及基于这些事实能作出的当下判断。配角的情绪通过停顿、站位、手势、递物和话语呈现，不写其独立内心。前三段的第一句必须是林时的具体动作。林时的盲区也必须成为叙事盲区：他不懂污染、学院长期计划、陆沉声音来源与西南机制，就不替他补答案。

**写作风格四字段：**
- 叙事身份：语言温度贴着林时的观察、迟疑和少量自嘲走，允许自由间接引语，但不滑入第一人称叙述。
- 不可违背信条：情绪通过细节、动作和物件传递；每节保留 1—2 处林时自我消解；对话口语化并区分声线；不为人物贴标签；第一人称只可出现在对话、备忘录或通信文字。
- 易犯错误规避：不用机械第三人称旁观；不让林时讲人生道理；陆沉不说长句；许岚干脆利落；贺鸣话多松散；顾铮准确克制。单节破折号不超过 15 个，“不是 X，是 Y”不超过 2—3 次，精准比喻不超过 1—2 个，至少半数小节停在日常动作、对话或沉默上。
- 描写层次：先给可见、可听、可触的事实，再让身体反应露出情绪；用电脑包、消息界面、空罐、多肉、登记页、训练表、灰纹、酸奶和台阶承载变化；高压段短句，日常段可松散；幽默来自反差、自嘲和降格，不用冷笑话遮掉危险。

**节奏、句式与信息：**
- 保持“紧 3 松 2”附近的交替，不连续超过 3 节纯高压，也不连续超过 5 节纯日常。夜巷、首次能力和陆沉失控是高压节点，其间用行动中的日常物件降噪。
- 高压段多用短句、单句段和动作断段；日常段句子可略长但不整齐。至少 25% 的段落可以单句成段；禁止连续 3 段句子数相同、连续 3 句同一主语或同一结构开头。
- 至少保留一段信息密度很低的日常闲笔，例如食堂路线、未喝完的酸奶、收拾多肉或贺鸣的无效抱怨；闲笔必须仍与路线、观察、互保或身体状态相连。
- 允许林时的情绪错位：最该追问时，他先盯住纸杯边缘或账单；最需要庆祝时，他先把灰纹藏进袖口。不要把所有反应写得正确、及时、完整。

**场景写法指引：**
- 夜巷环境与求生：林时是长期盯监控、走夜路的普通运维实习生，先注意异常的不是宏大异象，而是声音链断了、鞋底蹭水太响、手机光照到积水和旧广告。学院人员知道现场性质、林时不知道，因此林时的镜头只追能逃到哪里、谁挡住路、自己手背为什么发冷。紧张段以听觉与触觉压缩句子，金属声停下后再落一笔冷和耳鸣；不把巷子写成完整设定展示。
- 有限解释与权力对话：许岚掌握流程、林时要答案，两人的信息差要落在站位和动作里。许岚问一句就看一眼封锁线或观察表，回答只给“现在能做什么”；林时追问时捏着水瓶、收行李或删消息，用自嘲顶住失控。紧张时短问短答，中间插纸张、杯子、车门和脚步，不允许连续设定台词。
- 贺鸣、林时、陆沉的群像对话：贺鸣用食物和废话把空间撑开，林时只回一半，陆沉用碎词划界。三人的信息不对称是贺鸣知道日常规则、林时刚进入、陆沉听见更多却说不全；舒缓段可以有答非所问和停顿，但每次安静后都留一件能看见的危险物或身体征兆，例如未开的酸奶、按住的耳侧、袖口下的灰纹。
- “静”的效果：写结果、反应与代价，不拆招数或规则。陆沉能抬头、呼吸、把手放下是结果；林时指尖发冷、耳鸣、视野发白是代价；许岚下令撤离是边界。高压镜头快，撤离后的观察室和台阶放慢，让“短暂有效”而不是“成功解决”成为读者获得。
- 心理落点：不写“林时害怕、明白、意识到”。夜巷后可让他把母亲消息打了又删；取物时停在多肉、毕业证复印件和充电器之间；签字时笔尖停住、手背冷得发疼。重大抉择用身体、物件和未完成动作显示，不以总结句替代。
- 镜头与段落：一个镜头只承载一个动作单元，将事件、林时的感知和身体反应织在同一段里。镜头切换用林时的视线、听到的声音、递来的物件或碰到的人完成；不切到配角脑中，不提前给读者解释。

**叙事规则，优先级高于其他约束：**
1. 不用“他发现/意识到/感到”引导感知。林时熟悉告警、线路、加班和狭窄楼道，先写他会抓到的异常信号：声音断层、屏幕亮度、脚步回音、门禁灯和设备低鸣；他不懂异常体系，就只能保留疑问。
2. 只呈现动作结果，不替动作补机制因果。灰纹浮出、声音压低、陆沉能呼吸、林时站不稳，各自足够；不解释为什么会这样。
3. 讲故事，不表演情绪。林时的价值排序是“先别害人、也别逞英雄”，因此危险时先看同伴有没有站稳、自己有没有越线，再考虑答案；用他删掉的消息、收回的手、没写满的备忘录代替心理讲解。
4. 对话声线必须稳定：许岚短句命令、少解释；顾铮慢而准，用搪瓷杯和停顿切断未确认话题；贺鸣碎嘴、生活化、压力越大越爱提食物与报销；陆沉极短极碎，不分析；林时嘴上克制，偶尔用“差不多得了”式自嘲给自己留退路。

**反 AI 规则：**
- T1 禁用：`不是 A 而是 B`、`带着……`万能状语、`仿佛/犹如/宛若`、`让/令/使`因果引导、`当……时/的时候`、认知动词前置、`与此同时`。不用“突然、忽然、猛然”，让事件本身落下。
- 不用“瞳孔一缩、身体一僵、倒吸一口凉气、呼吸一滞、眼中闪过、嘴角勾起、陷入沉默、心中涌起、显然、毫无疑问、此时的他还不知道”等模板表达。以具体动作、身体反应或物件替代。
- 同一段内“然而/不过”最多留一个；“了”字密集、句号连续、等长段落、同一情绪词反复时主动打散。全文避免“重要/关键/核心”抽象复读。
- 不用元叙事、作者评语、章末升华和预告式全知句。章末不写“这一夜注定”“从这一刻起”“他不知道的是”。
- 对话打断用省略号或直接断句；全文破折号从严控制，强行打断最多一次。避免三段以上同开头、五句同句式、同一意象反复使用。
- 优先清理“终于、某种、好像、他觉得、他以为自己、这感觉像”等弱引导。林时可以自嘲，但不连续用食物比喻消解高压；食物类比优先放进贺鸣口中。
- 都市异能方向不套传统玄幻升级模板：不写血脉金光、废柴逆袭打脸、等级播报、境界压制、神兵收获或“我要变强”口号。能力成长必须是范围、协作和代价的微小进展。

### 约束红线

**冲突阶梯：**
1. 夜巷求生：林时想离开，异常对象与封闭小巷逼他停住；“静”救出处理窗口，也取消他立刻回家的资格。
2. 有限选择：林时想要真相并回原生活，学院只给监护、取物、记忆处理或观察的有限选项；他带行李回车上。
3. 能力不能替代人：林时想用“静”压住陆沉，能力只给短暂喘息并反噬；他学会边界和互保。
4. 留下后的入口：签入 A-2 后，西南信号进入训练场；林时获得任务方向，未知扩大。

**情节红线，不可删减：**
1. 林时的“静”首次有效使用必须与许岚等人的现场协作相连，并立即给出低温、耳鸣、疲惫、灰纹或视野发白等可见代价。
2. 林时在受监护回出租屋取物后，拒绝立刻记忆处理，选择进入学院观察；理由是已发生的身体事实无法被装作没发生，不是追求力量。
3. 陆沉失控时，“静”必须让他短暂安静，但不能治好他；许岚和顾铮必须阻止林时把自己当成唯一解法。
4. 章末林时签 A-2 入编观察，陆沉给出“西南/下面/别开太久”的碎片提示，许岚交付西南异常复核任务，固定第 2 章接口。

**边界禁止：**
1. 不解释污染来源、异世界、卵、学院扩招、清除政策、低剂量路线、记录风险或任何后期机制；不写完整能力机制、范围、长期上限、双通道或进攻用法。
2. 不引入或定名 A-12、黑月、可回应地址、015、DW-0、P-21、稳定记录；不正面引入苏晚，也不把旧物、旧照片、缺席人物与她作确定绑定。
3. 不把 P-21 与苏晚合并、暗示为同一对象或互相替代；不让孙浩获得污染诊断、能力表现、处置结果或结论。
4. 不以灰字、系统播报、解释性独白或总结性文字结尾；不把学院写成纯反派、万能安全屋或一次讲清真相的导师组织。

**角色禁区：**
- 林时不会以“静”单人解决夜巷或陆沉问题，不会喊口号式追求变强，也不会盲信学院。
- 许岚不会用亲近安慰替代边界，不会在本章交付未确认机制。
- 顾铮不会长篇讲述学院历史或替林时选边。
- 贺鸣不会把日常玩笑写成对危险的轻蔑，不会强逼林时或陆沉交代秘密。
- 陆沉不会长篇解释，不会输出西南信号的完整因果或后续谜底。

### 质感要求

**生活化闲笔：**
1. 林时挤地铁时把耳机线从电脑包拉链里拽出来；角落工位的冷气只吹到半边肩膀。
2. 多肉盆边沾着旧土，酸奶瓶盖总拧得不正，贺鸣把半个馒头掰得大小不匀。

**对话节奏：** 允许半截话、语气词、答非所问、无意义停顿与重复口头禅。许岚的停顿来自判断站位，顾铮的停顿来自拒绝补全，贺鸣的停顿常被废话填满，陆沉的停顿本身就是边界。不要把每一句话都写成信息交换。

**段落精度分层：**
- 高权重：夜巷失声、灰纹首次出现、陆沉短暂安静。细化动作、身体反应、关键物件和声音，但每段只保留一个镜头拍点。
- 中权重：据点、取物、登记、基础训练、签入编。正常推进，给选择和关系落地。
- 低权重：路线说明、食堂卡、洗衣房、无效抱怨、部分签到。允许略潦草的流水句和无效细节，不刻意抛光。

**不完美约束：** 允许人说不完整、说错重点、停在杯沿或台阶上不继续；允许林时备忘录删掉半句，贺鸣玩笑落空，顾铮把话留在“先过今晚”。拒绝每段都工整、每句都漂亮、每个物件都解释其意义。

**本章收束：** 最后一节停在林时把手背藏进袖口、写下“西南、信号、别开太久”，远处低频碰到“静”的边缘。任务尚未出发，答案不出现。
