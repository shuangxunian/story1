### 6. 规则：返修旧章必须同步下一章衔接点

- **阶段:** 章纲
- **类型:** 规则
- **领域:** 章节衔接 / 旧稿返修
- **原文:** 第三章新版合入时发现第四章章纲仍写旧第三章落点，如“宋清压下凌晨出入异常记录”“沈默用地图撤走”等，已改成新版第三章的旧变电站挂线、据点已空、许岚补训单和“有些人多了一晚”。
- **结论:** 返修已存在后续章节的旧章时，归档前必须检查下一章的“前章落点/衔接点/角色起点”，把旧事实替换成新版落点；否则后续正文会在开场接回旧版本。
- **场景:** 旧章重构、归档合并、下一章返修前、chapter-planner衔接检查
