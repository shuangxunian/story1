# 第四章·第097节：认真

程砚出现得很安静。

安静到林时第一眼看见的是门边那只干净的鞋。

A-2会议室的门没有完全关，宋清刚把新代号表夹进文件夹，贺鸣还站在饮水机旁边，手里拿着一次性纸杯。林时正准备把旧饼干铁盒塞回包里。

门被敲了两下。

程砚站在外面。

"方便吗？"

这三个字让屋子里的空气一下收紧。

贺鸣手里的纸杯被捏出一点凹痕。

宋清文件夹合得很快。

林时把铁盒推到桌下。

动作都不算大。

但每个人都动了。

程砚看见了。

他当然看见了。

这人连五分四十二秒都能写进记录，不可能看不见一个饼干铁盒在桌底下滑了一小截。

程砚没有进门。

他站在门口，视线落到桌上残留的纸屑、水杯和宋清的文件夹上。

"你们整理得挺认真。"

这句话很轻。

轻到像一句普通评价。

可会议室里没人把它当普通评价。

林时看着他。

"行政材料。"

宋清立刻接："A-2外勤后续记录。"

程砚点头。

"我没问内容。"

贺鸣低声说："你不问也挺吓人。"

宋清看他。

贺鸣闭嘴。

程砚像没听见。

"林时同学，复核期内临时权限调整已经生效。今天上午你没有调阅旧档。"

"嗯。"

"也没有登录公开资料库。"

林时看了宋清一眼。

宋清表情没变。

她用自己的权限查公开目录，这件事程砚知道。

或者至少，他知道林时没碰。

程砚继续说："很好。"

这个很好让人一点也不好。

林时说："你是来表扬我的？"

"不是。"

"那我放心了。"

程砚看着他。

"我是来提醒。"

又是提醒。

情报处的提醒像天气预报。说得温和，落下来可能是冰雹。

程砚从文件夹里抽出一张纸，没有递进来。

"D栋旧教学区昨晚生成一条本地异常日志。"

贺鸣的纸杯彻底瘪了。

宋清没有动。

林时看着程砚手里的纸。

异常日志还是长出了牙。

只是比他们预想中来得更快。

"跟我们有关？"林时问。

这句话说完，他自己都觉得像废话。程砚站在这里，当然不是来讨论旧电脑心理健康。

程砚却没有直接回答。

"日志显示退网终端缓存校验失败，联网同步未完成。没有有效账号，没有外接设备序列记录。"

没有外接设备序列记录。

林时听见这句，心里那根线松了半寸。

不是安全。

半寸而已。

程砚看着他。

"但复核期内，你最好不要再接近D栋旧教学区。"

林时问："这是限制？"

"提醒。"

"你们提醒的频率有点高。"

"因为你们违规的频率也不低。"

贺鸣说："你没有证据说是我们。"

程砚看向他。

"我也没有说是你们。"

贺鸣被噎住。

林时在旁边很想给他递一块酸苹果。

程砚的视线又落到宋清文件夹上。

"代号表？"

会议室里静了一瞬。

宋清没有否认。

"外勤观察对象保护。"

"做得对。"程砚说。

这次连宋清都抬了下眼。

程砚说："真实姓名不要和异常项目放在一起。"

林时看着他。

他用了异常项目。

不是S-07。

不是主动释放。

也不是旧档。

异常项目。

一个既不承认又不完全否认的词。

程砚把纸收回文件夹。

"我只是路过。"

贺鸣低声说："路过得很精准。"

程砚看他。

"谢谢。"

贺鸣："……"

林时觉得，如果有一天程砚和宋清开辩论赛，观众席可能会很安静，因为大家都被噎死了。

程砚转身前，又看了林时一眼。

"认真是好事。"

他说。

"但认真也会留下痕迹。"

门口的光落在他文件夹边缘。

干净，平直，像一条新画的线。
