# 第四章·第078节：培训

公开年报没有给出项目编号。

这件事并不意外。

第二天上午，宋清用自己的权限打开学院公开资料库，屏幕上跳出来一堆漂亮标题。污染源衰减研究进展，城市灾害响应机制优化，边缘区域异常预警模型。每一个标题都很端正，端正到像穿了正装参加会议，口袋里却可能装着刀。

林时站在她旁边，负责不乱动。

这个工作技术含量很低，但心理难度很高。

贺鸣评价他："你现在像被罚站的小学生。"

林时说："小学生至少不用看灾害管理年报。"

"那你惨一点。"

沈默坐在另一台电脑前，翻公开课程目录。他的鼠标滚得很快，页面一行行跳过去。宋清看了几次，最后忍住没有提醒。大概是因为沈默虽然看起来像在乱滚，眼睛却能在一堆课程代码里抓住异常。

十一点二十七分，沈默说："有一个。"

几个人同时看过去。

沈默把屏幕转了一点。

课程目录里有一条很旧的内部培训记录，日期在H-17事故后四个月。

课程名称：低剂量暴露识别与前驱干预。

培训对象：外勤组，后勤回收组，医疗观察组。

附件状态：已迁移。

迁移位置：D栋教学终端缓存库。

屏幕右侧还有一个很小的下载图标。

灰色。

不可用。

鼠标挪过去，弹出提示：旧版附件已离线迁移。

林时盯着那个灰色图标看了两秒。灰色很会装无害，像什么都没有，像旧资料过期，像系统维护遗留。可所有真正麻烦的东西最近都披着灰色外皮。灰色逻辑，灰色权限，灰色按钮，灰色地带。他甚至怀疑自己的近期生活可以改名叫学院灰度测试。这个想法一出来，他自己先嫌弃了一下。

不要给生活起标题。

尤其不要给烂事起。

林时看着那一行字。

低剂量暴露识别。

它从顾铮嘴里、H-17便签上，变成了一节培训课。培训课意味着有人教过，学过，签到过，考核过。伤害一旦变成课程，就不再只是某个办公室里的决定。它会分发，复制，变成很多人的操作手册。

贺鸣低声说："还培训。"

他的声音很轻，却压着火。

宋清把课程编号抄下来。

"附件已迁移，不在公开库。"

"D栋教学终端缓存库。"林时说。

沈默点头。

"旧教学终端可能有。"

宋清看向他。

"可能。"

"可能性高。"

"你一说高，我就觉得今晚要出事。"

贺鸣立刻接："你看，他连出事概率都提高了。"

沈默认真地说："我没有这个权限。"

林时差点笑出来。

宋清把编号写进笔记本，又在旁边标注：不登录，不复制，只核对目录。

"白天去D栋。"她说。

林时看了眼时间。

"现在？"

"下午。"

贺鸣问："为什么不是现在？"

"现在吃饭。"

这个答案非常宋清。

重大证据可能在旧终端里。

但中午要吃饭。

林时觉得这条规则很重要。不是因为饿，是因为他们不能把自己活成一条只会往下钻的线。线太细，会断。人得吃饭，得被薄荷糖冒犯，得听贺鸣嫌弃食堂茄子，得在证据旁边留一点日常。

否则真会被项目吞掉。

贺鸣站起来。

"那我申请吃面。"

宋清说："批准。"

"加卤蛋。"

"自费。"

"行政无情。"

林时把课程编号又看了一遍。

H-17后四个月。

低剂量暴露识别。

D栋教学终端缓存库。

这些词排在一起，像一串很安静的脚印。

脚印往D栋去。

他知道下午不会只是看一眼。

大家也知道。

只是没人现在说。

毕竟饭点到了。

人要活着查证据。

先吃饭。
