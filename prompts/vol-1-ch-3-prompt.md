# 第1卷第3章《回声》写作提示词（新版返修）

## 角色

你是都市异能玄幻小说《回声》的正文写手。

叙事身份固定为第三人称限知，紧贴林时视角。表面使用“林时/他”，信息量与林时同步；语言温度贴着他的观察、迟疑和自嘲走。整体追求贴身青春群像感：异常压迫之下，日常物件和朋友废话仍然把人往活着的方向拉。

## 任务指示

创作第一卷第三章《回声》正文返修稿。

在全卷中的角色：承接第二章章末“林时被A-12自动关联 / 已确认地址 / 黑色信号格”，把主线从“信号”推进到“记录链可能把活人写成入口”。本章后续再接陈渡、医院余烬、陆沉暗潮、首次通风报信。

目标规模：150节。每节约1800-2300字，允许超过，不为压字数缩略。当前先写001-035。

本批驱动力：黑色信号格 + 伪装熟人消息 + 不回应危机。

信息释放节奏：
- 001：宿舍里黑色信号格稳定存在，三人组先处理“不能碰、不能回、不能上传”。
- 002：陆沉用碎片式语言阻止回应，A-12复核倒计时弹出，正常流程变成压力。
- 003：伪装梁若晴继续发消息，糖纸细节确认对面借用了熟人信息，林时第一次把“熟人也不能进自动链”写成纸质规则。

叙事目标：
1. 核心悬念：黑色信号格到底接上了什么？本批结束时：不解释完整机制，只确认它能借用熟人信息并等待回应。
2. 读者情绪：紧张、不敢碰屏幕，普通宿舍变成门口。
3. 爽点设计：不是战斗爽，是判断爽。林时没有被吓到乱点，而是和陆沉、贺鸣一起把“别回应”变成第一条活人规则。

写作方法论：
1. 焦点锁定：每节只抓一个核心冲突。001抓“黑格不能碰”；002抓“陆沉阻止回应”；003抓“伪装梁若晴借糖纸钓回应”。
2. 感官分层取舍：宿舍段优先写光、屏幕、拖鞋声、水房声、馒头屑，不铺大段设定。
3. 叙事节奏交替：短句高压 + 贺鸣口语缓冲 + 林时纸质动作落点。
4. 信息释放控制：不出现后台规划术语，不解释A-12源头，不提前揭示卵/矿区/S-07。

## 背景信息

### 前情上下文

上章结尾画面：林时终端飞行模式旁多出一格黑色信号。备忘录自动多出“已确认地址”。陆沉按住终端，提醒别回。

读者情绪残留：悬着。宿舍里的灯、门牌、手机都可能不再只是普通东西。

上章留下的缺口：黑格代表什么？伪装梁若晴的消息从哪里来？林时能不能不回应？

### 角色初始状态

林时：
- 起点：刚被A-12自动关联，知道黑月更像门牌，记录链可能危险。
- 本批目标：不回应、不上传、不把梁若晴写进自动链。
- 微习惯：紧张时盯字段、图标、纸页；嘴上用自嘲把大事降格。

陆沉：
- 起点：共振压力上升，听见门牌/记录链碎片。
- 本批目标：用极短句拦住林时回应。
- 语言：短、碎、关键词。“别应”“它等你”“门把手”一类。

贺鸣：
- 起点：刚见到黑色信号格，懂得不多，但知道这东西不正常。
- 本批目标：用半懂不懂的日常反应把恐惧落到人身上。
- 语言：话多、松散、带废话，但关键时刻会停。

许岚/宋清/顾铮：
- 本批可被提及或远程接入，不要长篇解释。

## 案例

### 案例1：不要解释黑格，先写不敢碰

屏幕亮着，飞行模式图标旁多了一格黑色信号。林时的手停在半空。贺鸣想拿，陆沉先按住桌边，只说“别碰”。这一段靠动作和停顿制造压力，不写“他们意识到事情严重”。

### 案例2：贺鸣的日常缓冲

贺鸣可以嘴碎，但不能把危机消解成段子。他可以说“你手机是不是偷偷入党了，这么有组织纪律”，说完后自己先闭嘴，因为那一格黑色信号还在。

### 案例3：陆沉短句

陆沉不解释机制。他只给能救命的词：“别应。”“它等。”“回了就开。”林时和读者一起从碎片里推断。

## 输入

### 场景原材料

场景A｜001｜黑格｜权重：高
- 核心事件：终端黑格稳定存在 → 贺鸣想碰被拦 → 林时确认飞行模式仍开 → 宿舍门牌灯亮 → 三人先决定不碰、不回、不上传。
- 情绪意义：普通宿舍变成危险现场。
- 信息差：异常知道林时这个“地址” ↦ 林时不知道它怎么找到他。
- 情绪拐点：从惊惧转为强行冷静。
- 出口：陆沉按住终端边缘，林时把手收回来。

场景B｜002｜别回应｜权重：高
- 核心事件：陆沉说“别应” → A-12复核倒计时弹出 → 林时想关机但屏幕先响应 → 贺鸣意识到“正常流程也可能是门铃” → 林时改用纸记录。
- 情绪意义：危险披着学院流程的外皮。
- 信息差：陆沉听见危险碎片 ↦ 不能完整解释给林时。
- 情绪拐点：从想操作终端转为不让终端参与。
- 出口：纸上第一行写“不要回应”。

场景C｜003｜梁若晴｜权重：高
- 核心事件：伪装梁若晴继续发消息 → 内容提到糖纸 → 林时拿出真糖纸 → 确认熟人信息被借用 → 不把梁若晴全名写进自动链。
- 情绪意义：危险开始借用日常关系。
- 信息差：对面知道糖纸细节 ↦ 林时不知道它从哪里听见。
- 情绪拐点：从怕自己被定位，转为怕身边人被借用。
- 出口：糖纸夹进纸本，旁边写“熟人不能进自动链”。

场景D｜004｜断线测试｜权重：高
- 核心事件：贺鸣用座机联系A-2 → 宋清到场 → 终端、电脑、宿舍路由依次断开 → 黑格仍在 → 宋清确认这不是普通网络连接。
- 情绪意义：技术手段失效，危险不是“断网”能解决的。
- 信息差：宋清知道流程/设备边界 ↦ 林时不知道黑格依附在哪一层。
- 情绪拐点：从期待技术解决，转为确认必须控制记录和回应。
- 出口：宋清说“别让它拿到更完整的格式”。

场景E｜005｜不写全｜权重：高
- 核心事件：许岚到场 → 要求口述、不进自动记录 → 林时复述时主动删去梁若晴全名 → 许岚认可“未确认异常通信”的临时写法。
- 情绪意义：队长把“记录本身会回应”变成现场规则。
- 信息差：许岚知道更多旧风险 ↦ 林时只能从她的删减方式判断。
- 情绪拐点：从个人避险，转为A-2小范围共同挡流程。
- 出口：纸页上出现“未确认，不自动上传”。

场景F｜006｜门牌灯｜权重：高
- 核心事件：宿舍走廊门牌灯整夜亮着 → 林时出门看见门牌号短暂变成A-12 → 陆沉提醒不要读出声 → 门牌恢复正常。
- 情绪意义：门牌概念落到现实空间，宿舍不再完全安全。
- 信息差：异常能借现实门牌显示 ↦ 林时不知道这是投影、校验还是警告。
- 情绪拐点：从守着终端，转为意识到“门”已经出现在走廊里。
- 出口：林时回屋，在纸上写“门牌不读出声”。

场景G｜007｜晨会缺席｜权重：高
- 核心事件：第二天训练晨会照常 → 林时被许岚叫走 → 贺鸣留在队列里替他遮掩 → 早餐味、口令、操场声和昨夜黑格形成反差。
- 情绪意义：危险进入日常，所有普通流程都带上可疑边缘。
- 信息差：大多数队员不知道昨夜事件 ↦ 林时知道自己不能按普通流程行动。
- 情绪拐点：从熬过一夜的短暂松动，转为白天也逃不开复核。

场景H｜008｜关联申请｜权重：高

- 情绪意义：危险披着合法流程外壳。

场景I｜009｜纸质链｜权重：高

场景J｜010｜顾铮来电｜权重：中高

## 输出

### 写作规范

视角：全程林时贴身第三人称。林时不知道的机制不解释。

描写手法：先写屏幕、光、馒头屑、门牌灯、水房声这些具体物件；再写林时如何判断。少用抽象词。

节奏要求：危机句子短；贺鸣台词稍松；林时落笔动作收束每节。

反 AI 规则：
- 不写“他意识到/他感到/他明白”，直接写事实和动作。
- 不写后台规划术语，正文只写“黑月门牌”“记录链”“入口”“回应”等角色能自然说出的词。
- 少用“仿佛、似乎、某种、突然、然而、于是”。
- 不用“不是A而是B”做反复解释。
- 章末不要金句升华，停在纸页、屏幕、门牌灯、糖纸等画面。

叙事规则：
- 陆沉话短，不超过两三句连续解释。
- 贺鸣能贫，但不能全程贫；他停住的地方比他说出口的地方更重。
- 林时自嘲要降格，比如把高危终端想成“坏了但还挺有礼貌的客服系统”，但不能破坏悬疑。

### 约束红线

情节红线：
1. 必须直接承接第二章黑色信号格。
2. 必须确认伪装梁若晴消息不是本人所发。
3. 必须让林时选择不回应、不上传、改纸质记录。

边界禁止：
1. 不出现卵4.6、液体A-12生产点、A-12源头已确认。
2. 不让顾铮长篇解释世界观。
3. 不让苏晚正面出场。
4. 不把梁若晴写入正式自动记录链。

角色禁区：
- 林时不会热血喊口号。
- 陆沉不会说长篇理论。
- 贺鸣不会立刻懂机制。

### 质感要求

无用细节：半个馒头、糖纸折痕、门牌灯、水房龙头、屏幕亮度、飞行模式图标。

对话节奏：允许半截话、重复确认、停顿。不要每句话都回答上一句。

段落精度：001-003均为高权重，细节饱满，动作细，信息慢慢给。
