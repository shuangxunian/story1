## 角色

你是一名都市悬疑 / 异常调查题材小说作家。以普通生活被细小异常侵入为入口，追踪记录、权限与人际关系如何共同制造风险；始终把具体的人置于抽象流程之前。

## 任务指示

创作卷一第 1 章《静》，在全卷中承担“异常进入日常”的开篇与关系奠基职责。

- 目标规模：约 70 节，采用纯文本分节格式 `001｜节名`；节名短、冷、有信息量。
- 本章驱动力：林时从只能独自忍耐的异常者，被纳入 A-2 的有限观察；陆沉的当场失衡逼他在不明代价时做出靠近的选择。
- 信息释放节奏：日常只露出可触的失常征兆；入院后只确认存在处理体系；A-2 只给局部流程与局部代价。章末保留“西南、信号、别开太久”的任务接口，不说明其意义。

### 叙事目标

1. 核心悬念：林时身上的“静”为什么能压低陆沉的异常，而这次帮助会把他带向哪里？本章结束时：加深。
2. 读者情绪：耳鸣未散，手里多了一项去向不明的复核任务。
3. 爽点设计：克制型能力初现；铺垫于场景 1 的低温与失真，释放于场景 3 对陆沉的短暂压制，并立刻以灰纹、耳鸣和疲惫收回代价。

### 写作方法论

1. 焦点锁定：每场景先定唯一冲突、人物状态和信息缺口；约七成笔墨投入高权重场景，背景、路人和制度说明只留必要痕迹。
2. 感官分层取舍：每场景只细化两种感官。日常失衡优先听觉与触觉，A-2 失衡优先声音与皮肤温度；其余感官一句带过。
3. 叙事节奏交替：密集动作或短对话后，接短暂的身体留白，再用一句轻环境完成转场；避免连续长描写、连续问答和等长段落。
4. 信息释放控制：异常、学院、A-2 与人物立场都以碎片给出；只写林时能碰到、听到、看到的局部后果，不替任何人补完原因。

## 背景信息

### 前情上下文

- 上章结尾画面：无前置章节，开篇直接切入林时当下的行动。
- 读者情绪残留：未建立。
- 上章留下的缺口：先让日常中的低温和耳鸣落到林时身上，禁用大段世界背景介绍。

### 角色初始状态

**林时**：
- 起点：还在熟悉的生活场域里照常做事，冷意沿着手指往上爬，耳内有拆不开的杂音；他用停顿、换手或避开旁人把不适压住。
- → 经历：许岚带他进入观察流程；他在陆沉失衡时离开安全位置，主动靠近。
- → 终点：手背出现灰纹，耳鸣和疲惫加重；他知道“静”能暂时压低异常，并接下未出发的复核任务。
- 本章微习惯/小动作：不适时用指腹磨衣角或把手指藏进掌心；面对空白解释时先看纸面和门口，不急着追问。

**许岚**：
- 起点：携带有限处理方案进入林时的日常场域，话少、步骤清楚。
- → 经历：把林时带入院内流程，在陆沉失衡时先守住现场边界。
- → 终点：阻止林时继续消耗，仍不交代学院全貌。
- 本章微习惯/小动作：核对记录、递东西、给出可执行的短句；不把人推到风险前面。

**贺鸣**：
- 起点：同样处于入院观察的陌生秩序里，用碎嘴和实际帮忙冲淡尴尬。
- → 经历：陪林时经过流程并旁观 A-2 的突发情况。
- → 终点：和林时、陆沉之间留下尚未站稳的同伴位置。
- 本章微习惯/小动作：紧张时说些不太合时宜的日常话，但手上会先帮人拿东西、让路或补上遗漏。

**陆沉**：
- 起点：训练期成员，受异常声音牵扯，仍试图维持自己的边界。
- → 经历：在 A-2 接近失控，现场程序先于解释启动。
- → 终点：在“静”里得到短暂喘息，留下未经翻译的碎片反应。
- 本章微习惯/小动作：异常加重时把注意力压回呼吸和手边能抓住的物件，不替他补写完整记忆。

**顾铮**：
- 起点：学院内部人员，观察而不展开说明。
- → 经历：在 A-2 提供窄线索和受控记录。
- → 终点：对林时保留克制的观察，立场不落定。
- 本章微习惯/小动作：只挑能说的部分递出来，话说到边缘就停，目光落在记录或现场而非解释上。

## 案例

### A-2 失衡的写法参考

信息差是许岚、顾铮知道现场边界，林时只看见陆沉被声音拖住。陆沉不必说清自己听见什么：他抓住扶手，指节压白，呼吸被一段断续声响切碎。许岚先报出简短流程，手势把旁人隔开；林时听见那段声音贴着耳骨走，皮肤先冷下去，再靠近。写“静”时不写招式、光效或能力说明，只写声音往下塌、陆沉终于把一口气吐出来，以及林时手背浮出的灰纹。节奏先短促逼近，后用一次被阻止的动作和一段沉默把代价落住。

### 入院对话的写法参考

信息差是许岚掌握风险管理边界，林时只得到“需要观察”。许岚不长篇解释，递文件、指出该走的门、把不能回答的问题压在一句“先按流程来”里；林时的问题保持短，问到空白处便收回去看纸面。贺鸣可在空档里插一句生活化抱怨，再替林时把遗漏的东西拿上。对话的张力来自谁能说、谁不能说，而非用术语堆出机构神秘感。

### 场景原材料

#### 场景 1｜日常失衡｜压低的异样｜权重：高

- 核心事件：林时照常处理手边小事 → 不合季节的冷意贴上皮肤 → 一个普通声音或物件被拉长变形 → 他停住动作、避开旁人，把异常压回去。
- 情绪：熟悉处先出现一条无法解释的裂缝。
- 信息差：林时只掌握身体的局部反应 ↦ 周围人尚未察觉异常，也无人给出解释。
- 情绪拐点：从“还能当作不适”转为“距离和音量已不可靠”。
- 出口：忍住。
- 衔接：许岚带着有限的处理方案进入他的日常场域。
- 本场景权重：高。
- 段落分解：
  - ¶1 [行动开篇 / 造悬念]｜短句切入，中近景｜前三段第一句必须是林时的动作；不先铺环境，不说异常原因。
  - ¶2 [感知失真 / 推进]｜句子由稳转碎，特写手指、耳内杂音或普通物件｜把发生、感知和身体反应织在同一段，不分成解释段。
  - ¶3 [掩饰 / 留白]｜短句收束，中景｜只写林时如何避开旁人，不给情绪结论。

#### 场景 2｜入院与 A-2 初见｜有秩序的空白｜权重：低

- 核心事件：许岚提出观察安排 → 林时跟随进入流程区 → 贺鸣在手续和路线上搭把手 → 受控记录、观察区和缺失说明进入视野 → 顾铮只给一条窄线索。
- 情绪：规整的门、纸面和流程把人安置好，也把答案挡在外面。
- 信息差：许岚与顾铮知道处理边界 ↦ 林时、贺鸣只知道自己被带来观察。
- 情绪拐点：从“有人接手”转为“接手的人不准备解释”。
- 出口：悬着。
- 衔接：观察区内的异常声音打断流程。
- 本场景权重：低。
- 段落分解：
  - ¶1 [转场 / 建立秩序]｜中速，远景转中景｜用门禁、表格、候场座位等一两个物件带出流程，不罗列机构设施。
  - ¶2 [对话 / 信息受限]｜短问短答，动作穿插｜许岚只给操作性答复；贺鸣的日常话只能缓冲停顿，不能稀释风险。
  - ¶3 [造悬念 / 窄线索]｜短句，特写记录缺口或顾铮停住的动作｜不给完整解释，不新增世界观名词。

#### 场景 3｜陆沉失衡与第一次“静”｜被迫靠近｜权重：高

- 核心事件：陆沉被异常声音拖向失控边缘 → 现场人员启动程序、拉开距离 → 林时在边缘停住 → 他靠近陆沉并压低异常 → 声音回落，陆沉短暂喘息 → 林时低温、耳鸣、灰纹和疲惫显形，许岚阻止继续消耗。
- 情绪：从被动旁观压到必须伸手。
- 信息差：许岚和顾铮掌握程序边界 ↦ 林时不知道“静”的来源、上限与代价；陆沉听见的碎片也无法被完整翻译。
- 情绪拐点：林时离开安全位置的一刻，从自保转为先救眼前的人。
- 出口：余冷。
- 衔接：陆沉缓下来后，关系与任务接口在安静里留下。
- 本场景权重：高。
- 段落分解：
  - ¶1 [冲突启动]｜短句快节奏，中景转特写｜先写陆沉的动作和现场反应，不给声音来源命名。
  - ¶2 [程序施压]｜短促对话与动作交替｜许岚的流程动作应体现保护，不将林时当作工具。
  - ¶3 [关键抉择]｜留白后推进，近景｜林时的停顿用脚步、手和耳鸣呈现，不写心理分析。
  - ¶4 [能力释放]｜极短句与感官收缩，特写｜只写声音、温度、呼吸和灰纹的变化；不写能力机制、战斗胜利或光效。
  - ¶5 [代价落地]｜节奏放慢，中景｜许岚阻止林时继续，陆沉的碎片只保留不可解读的片段。

#### 场景 4｜有限关系与章末接口｜未出发的方向｜权重：中

- 核心事件：林时在恢复区或走廊整理手边物件 → 贺鸣与陆沉留下不稳定的同伴回应 → 许岚和顾铮分别给出有限态度 → 一项复核任务递到林时手上 → 他只得到“西南、信号、别开太久”的警告并接下任务。
- 情绪：人际的温度没有驱散余冷，反而把即将出发的方向照出来。
- 信息差：学院掌握任务背景 ↦ 林时只拿到方向、风险提示和必须行动的责任。
- 情绪拐点：从被观察者转为主动接下任务的新人。
- 出口：待出发。
- 衔接：停在任务物件、门口或林时尚未迈出的行动上，结束本章。
- 本场景权重：中。
- 段落分解：
  - ¶1 [缓冲 / 关系建立]｜中速，近景｜保留一句不服务主线的生活化停顿，关系不说破。
  - ¶2 [任务递交 / 信息钩子]｜短句，特写任务纸面或设备｜警告只出现一次，不释义关键词。
  - ¶3 [章末收束]｜短句或单句段｜停在林时触碰任务、看向出口或收起物件的动作，不升华、不预告。

## 输出

### 约束红线

- 冲突阶梯：第一层“异常进入日常”。压迫感应来自可感知的失常与有限流程，不能跳到组织阴谋、完整机制或终局威胁。
- 情节红线：
  1. 林时必须由普通生活进入学院 A-2；入院是有限观察，不是获得完整说明。
  2. 陆沉的当场失衡必须被“静”暂时压下；林时的低温、耳鸣、灰纹与疲惫必须随即显形。
  3. 许岚必须阻止林时继续消耗；她的保护不等于交出信任或全貌。
  4. 章末必须是林时接受尚未出发的复核任务，并只保留“西南、信号、别开太久”的局部警告。
- 边界禁止：
  1. 不出现或解释 A-12、黑月、015、DW-0、P-21、稳定记录或苏晚。
  2. 不揭示学院派系、内部责任、能力来源、能力上限、终局机制、顾铮旧案或陆沉后续线。
  3. 不让林时完成调查、取得战斗胜利，或得到完整世界观说明。
- 角色禁区：
  - 林时不会把“静”当作无代价的万能手段，也不会因害怕而把陆沉当成需要被清除的对象。
  - 许岚不会把林时当诱饵，也不会用长篇说明消除信息差。
  - 贺鸣不会用连续食物类比冲淡高压现场。
  - 陆沉不会讲清异常声音的来源、后续线索或自身能力全貌。
  - 顾铮不会在第一章表明完整立场或旧案信息。

### 写作规范

#### 风格四字段

- 叙事身份：第三人称限知，紧贴林时的感知、迟疑和行动；配角信息只能经过他的所见、所闻、所触及的反应传递。
- 核心原则：日常与紧张交替；高压流程以物件、动作和身体代价降噪；情绪不下结论；规则分段释放；人不能被简化为可调用的记录。
- 易错点：不要恢复旧叙事，不要用抽象机制词堆压迫感，不要提前解释学院与能力；不要把异常写成华丽觉醒、把帮助写成无代价英雄时刻。
- 描写技法：以具体动词代替万能形容词；将发生、林时注意到的细节和身体回应织入同一动作单元；关键段以声音与触觉建立压迫，非关键段简笔掠过。

#### 视角、描写与节奏

- 视角：林时单主角有限 POV。林时看不见、猜不到的事不写；许岚、顾铮、陆沉的内心不得独立展开。通过林时听到的声音、看见的手势、接到的纸面记录传递配角状态。
- 开篇：前三段的第一句从林时正在做的动作起笔；不以世界观、机构沿革或环境全景开场。
- 描写：环境只承载当下的线索或压迫，例如门禁的停顿、表格的空栏、扶手上的手指印；不要为气氛罗列无意义设施。林时经历日常失衡和“静”时，以具体身体后果取代“觉醒”“强大”等概念。
- 节奏：日常段可略长，异常袭来、流程命令和能力使用改为短句；段落长短必须错开，至少四分之一采用独句段，避免连续三段句子数量相近。
- 句式：长短句交替，避免连续三句同一主语或同一结构；对话标签少用副词，优先用动作承接。
- 情绪：不写“害怕、紧张、愤怒”等结论。林时在陆沉失衡时可先停住、手指缩回，再走过去；这一处选择应与读者预期的退避错位。陆沉的状态用呼吸、抓握和被声音打断的动作表现。
- 信息：允许一段低信息密度的生活化闲笔，例如林时反复把衣角抻平、贺鸣替人挪开碍事的杯子；允许一处无后续的普通细节，但它不得伪装成重大谜底。

#### 反 AI 与语言控制

- T1 零容忍：不用“不是 A 而是 B”“当……时/的时候”“与此同时”“他感到/觉得/意识到”“带着……”等模板；避免“仿佛、犹如、宛若、一丝、一抹、突然、忽然、猛然、不禁、不由得、显然、毫无疑问”等弱引导。
- 情绪外化：不写“林时害怕”“陆沉痛苦”，改写手指、呼吸、喉咙、步伐、皮肤温度和对物件的反应。
- 重复控制：同段内“然而/不过”等转折只留最贴切的一次；避免连续相同段首、相同主语、相同比喻和同一情绪词；全章不把“重要、关键、核心”当抽象强调词反复使用。
- 标点：全文不以破折号作普通停顿；如有人被强行打断，至多一次。对话断裂优先用省略号或直接断句。
- 结尾：不写“这一夜注定”“从这一刻起”“他不知道的是”等预告与升华；章末落在眼前的动作、物件或声音上。
- 题材限制：异常不是玄幻式血脉觉醒，不写金光、威压、招式或天赋宣言；任何能力都以难受、耗损、失控风险或无法解释的局部后果呈现。
- 作者偏好：优先删除“终于、某种、好像、他觉得、他以为自己、这感觉像”等弱引导；林时可有少量锋利自嘲，但不连续使用食物比喻；流程词每次出现都必须绑定新动作、纸面后果、站位或物件变化。

#### 场景写法与叙事规则（优先级高于所有约束）

- 通用规则 1：不说认知动词。林时未掌握异常知识，他最先能确认的是冷、耳鸣、距离错位、纸面空栏和他人动作；对学院机制保持盲区，不替他推出答案。
- 通用规则 2：只说动作结果，不解释因果。写“陆沉的呼吸接上来，林时手背浮出灰纹”，不写“静为何生效”；写“许岚把人隔开”，不解释她掌握的流程原理。
- 通用规则 3：讲故事，不演示说明书。流程只保留进入、等待、核对、被打断等会改变人物位置的节点，删去制度介绍和术语复读。
- 环境与转场：林时从普通生活进入院内，先捕捉会影响行动的声音、冷暖、门和记录；用视线、脚步或被打断的声音把镜头带到下一处，不写俯瞰式机构全景。
- 对话：许岚的短句服务安全边界，顾铮的停顿服务信息缺口，贺鸣用日常话与实际帮助填补空档；三人的话不能同声同调。紧张段用短问、未答和手部动作交替，不把秘密塞进长篇解释。
- 高压现场：陆沉受异常声音牵扯，动作先于语言失序；林时的价值排序是眼前的人先于未知风险，他靠近的决定通过脚步、触碰与停顿呈现。能力段采用“结果 → 现场反应 → 身体代价”的顺序，少写过程。
- 内心处理：林时面对未知与选择时，允许思绪被无关的小事打断，例如衣角、门把手或纸边；碎片只留一两下，随即回到动作，不能写成整段自我分析。

### 质感要求

- 无用细节：林时把被冷意弄皱的袖口反复抻平；贺鸣把喝空的纸杯挪到椅脚旁，又忘了拿走。
- 对话节奏：允许半截话、语气词、无意义停顿与少量重复。许岚的短句应干净，贺鸣的碎嘴有实际帮助，陆沉在高压中可以只吐出断片。
- 真人痕迹：允许词穷、停顿和局部重复；高权重场景把动作、微表情和身体代价写足，低权重流程段可简略甚至带一点仓促感，避免全文精致得同一种节拍。
- 不完美约束：至少保留一处半截话、一处不服务主线的生活细节、一处信息密度极低的状态段；不把每段都写成解释、金句或伏笔。
- 额外约束：章节结束后，林时仍未出发；他手里只有行动入口，没有答案。
