# rebuild-v1 资料权威层级

## 适用规则

资料按用途分类，不以文件存在与否自动判定 canon。发生矛盾时，先记录到 `rebuild/contradiction-ledger.md`，再由作者作出重构裁决。

1. **作者后续明确裁决**：对其指定议题拥有最高优先级。
2. **重构期确认的 canon**：仅限后续在 `rebuild/changes/` 中明确登记并经确认的改动。
3. **现行设定与项目主线索引**：`settings/` 与 `story.md` 是当前工作假设的主要来源，需与作者裁决核对。
4. **现行章纲与提示词**：`chapters/`、`prompts/` 是计划与执行痕迹，用于还原意图，不单独确立事实。
5. **旧正文与旧文档**：`archives/`、`docs/` 是保留参考，用于证据、版本比对和矛盾发现，不自动 canon。
6. **状态、记忆与计划文件**：`.agent/status.md`、`.claude/memory/`、`02-写作计划.json` 是流程或历史上下文；可提示待核问题，不单独覆盖上层资料。

## 分类规则

- **现行设定**：定义角色、世界、题材、写作风格和时间线的资料。
- **主线索引**：汇总章节目标与已知承接关系的资料。
- **规划资料**：描述预期章节结构或写作指令的资料。
- **正文证据**：已有正文及其草稿，记录曾经写出的版本事实。
- **历史文档**：旧版规划、修订、连续性与扫描记录，保留但不自动升级。
- **流程上下文**：进度、动态记忆、外部计划数据，作为线索而非 canon。
