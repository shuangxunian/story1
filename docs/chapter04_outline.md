# 第四章：灰色（工作纲）

## 核心方向

第三章末，林时第一次通风报信救走陈渡据点。第四章不立刻让他逃亡，而是让他继续待在学院内部承受后果：情报处复核、门禁记录、宋清/许岚/沈默的灰色默许，以及越来越清晰的学院主动释放污染源证据链。

本章目标：把读者认知从"学院默许A-12投放"推进到"学院有可编号、可执行、可追踪的低剂量唤醒项目S-07"。

## 情绪走向

侥幸活下来 → 日常里被审查盯住 → 查到H-17事故线 → 安置点受害者让证据落到活人身上 → S-07项目浮出水面 → 院长周临渊正面出场并承认。

## 关键支点

- 情报处程砚复核城西泄密，但不脸谱化。
- 宋清用流程帮林时挡一次，体现"填表也能挡一下"。
- H-17事故报告指向低剂量缓释技术。
- 安置点男孩和周可把项目编号落到普通人身上。
- 苏晚留下管道叉号，暗示她知道S-07路线。
- 章末周临渊承认主动释放，并推来"第一次入侵后幸存率推演"。
